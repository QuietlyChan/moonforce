# moonforce (MoonBit package)

A force-directed graph layout engine with bit-level d3-force 3.x semantic alignment. This file is the module documentation for [mooncakes.io](https://mooncakes.io); for the full introduction, benchmarks, and comparisons see the [README](README.md).

## Install

```bash
moon add QuietlyChan/moonforce
```

## Packages

| Package | Purpose |
|---|---|
| `QuietlyChan/moonforce/src/types` | SoA node pool (`NodePool`), lcg random source |
| `QuietlyChan/moonforce/src/quadtree` | d3-quadtree-aligned loose quadtree |
| `QuietlyChan/moonforce/src/forces` | 7 forces (`Force` enum static dispatch) |
| `QuietlyChan/moonforce/src/simulation` | `Simulation` tick state machine (`ForceKind` for removal) |
| `QuietlyChan/moonforce/src/ffi` | wasm export layer (foreign_library, `#export_name`) |

## Minimal example

```moonbit nocheck
///|
import {
  "QuietlyChan/moonforce/src/simulation",
}

///|
import {
  "QuietlyChan/moonforce/src/forces",
}

///|
test "force-directed layout" {
  let sim : @simulation.Simulation = @simulation.Simulation::new(6)
  // Force insertion order = d3 Map insertion order; it affects the trajectory
  ignore(
    sim.add_force(@forces.Force::ManyBody(@forces.ManyBodyForce::new(6, -30.0))),
  )
  let link : @forces.LinkForce = @forces.LinkForce::create(6, 30.0, 1)
  link.add_edge(0, 1)
  link.add_edge(1, 2)
  ignore(sim.add_force(@forces.Force::Link(link)))
  ignore(sim.tick(300))
  assert_false(sim.nodes.xs[0].is_nan())
}
```

## Numeric alignment

Bit-level aligned with d3-force@3 (coordinate error < 1e-9 over 300 ticks); golden fixtures are generated by `scripts/golden.mjs`. See the "Semantic Alignment" section of the [README](README.md) for details.
